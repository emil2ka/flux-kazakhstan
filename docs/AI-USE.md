# FLUX · Журнал использования ИИ

Обновлено 27 октября 2026 для финала. ИИ помогал с исследованием, черновиками, кодом, финансовой моделью, проверками и визуальным оформлением. Указания по продукту и стилю, правки и цена 55 000 тенге задавались командой. Этот файл - журнал, а не полный экспорт частной переписки.

- Command Code / DeepSeek V4.1 Flash: восемь исследовательских сессий по рынку, конкурентам, продукту, платежам, экономике, MVP, привлечению и правилам; по сохранённому журналу первого этапа.
- Codex: чтение источников, редактирование кода/текстов, перерасчёт, сборка PDF, браузерные проверки.
- Flow: фотографии и логотип исходного прототипа, по журналу первого этапа. Пейзажи иллюстративные.
- Встроенный ImageGen: генерация и редактирование слайдов. [Промпты 2/4/7](image-prompts-a.json), [промпты 3/5/6/8](image-prompts-b.json). Первый слайд сохранён из ранее согласованной версии.
- Python и Playwright: расчёты, обработка первичной статистики, реальные скриншоты страниц и автоматические проверки.

Изменения финала: одно демонстрационное предложение на Чарын по 55 000 тенге; проверка конфликта трансфера; публикация версий; неизменяемый снимок принятых условий; локальная бронь и скачивание подтверждения; русская версия для защиты. Поддержка в смете исправлена с 9 на 12 месяцев, итог проекта 7,425 млн; с проведением туров 18,150 млн; окупаемость 15/18 месяцев.

Проверены [первичная таблица БНС](https://stat.gov.kz/api/iblock/element/415852/file/en/), [кейс](https://docs.google.com/document/d/1MC9xKU-zH8G1bEbcZM_Qpjw3cPcs9tL29gLcB0NCNw0/edit) и [регламент финала](https://docs.google.com/document/d/1Oir2Izl827gC0uCQyh7fm7UaPKgzI6D-r0e-EQ3_s00/edit). В таблице БНС за 2025 год, лист By purpose of the trip, AA52 = 87 257 частных въездов граждан Германии. Въезды не подменяются уникальными покупателями. Уточнение про единый язык взято из скриншота сообщения организаторов, предоставленного командой.

Готовность не преувеличивается: нет подтверждённых интервью, договоров, продаж, эквайринга, серверной базы, авторизации и почтовой доставки в финальном сценарии. Маржа и привлечение в расчёте - плановые допущения. [Помесячная модель](economics-final.json). Арифметика воспроизводится в final/source/build_model.py в комплекте команды.

Официальная шкала Levels of AI Use организаторами не предоставлена, что подтверждено командой. Номер уровня не указан; фактический вклад перечислен выше. Исходные чаты и локальные идентификаторы сохранены у команды; публичная ссылка на весь диалог не создавалась.

Обновление 28 октября: полный русский перевод сайта (интерфейс, маршруты, программы, поиск и метаданные), проверка 36 сочетаний страниц/экранов. Финальный слайд использует предоставленные командой фотографии; оформление и позы обработаны ImageGen.
