# FLUX: использование ИИ

Текущая версия: однодневный Чарын за 44 000 ₸, англоязычный гид. Эмиль отвечает за бэкенд и исследование, Хакназар — за фронтенд и презентацию. Роли обозначают ответственность, а не отсутствие помощи инструментов.

- Command Code / DeepSeek V4.1 Flash и Codex помогали искать и анализировать источники, сравнивать предложения, готовить черновики исследования.
- Codex помогал с логикой бронирования, локализацией RU/DE/EN, именными PDF-билетами, расчётами, проверками и подготовкой документов.
- Flow использовался для исходных иллюстраций и логотипа по журналу первого этапа. ImageGen создавал и редактировал визуалы слайдов, включая композицию предоставленных фотографий команды. Два слайда с числами используют нативный PDF-текст.
- Python использован для таблиц БНС и воспроизводимой арифметики, Playwright — для браузерных проверок и скриншотов. Это программные инструменты, а не модели ИИ.

Команда выбрала формат и цену, предоставила фотографии и направляла правки дизайна. Исходные чаты, промпты и сценарии сохранены локально; история предыдущих вариантов отделена от текущих материалов. [Промпты финальной правки](image-prompts-final44.json), [расчёт](economics-final.json).

Данные о въездах не названы покупателями. Новые интервью, продажи и договоры не заявляются. Финансовые ставки, цена и спрос остаются допущениями. MVP хранит бронь в браузере; платежей и отправки писем нет. Живой перевод и спутниковый интернет в текущий продукт не включены.

Организаторы не предоставили официальную шкалу уровней использования ИИ; номер уровня не придуман. Полный приватный диалог публично не публиковался. Команда отвечает за точность представленных материалов.
